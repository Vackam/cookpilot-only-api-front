# feat/netflix-style-home — 넷플릭스식 카드 홈 이식 (메인 저장소 PR #63 디자인)

## 문제 상황

홈이 세로 목록 하나였다. 최근 조리·즐겨찾기·전체 레시피가 같은 모양의 68~76px
썸네일 타일로 세로로 쌓여, 한 화면에 3~4개밖에 안 들어오고 위계가 없었다.
메인 저장소 PR #63(feat/netflix-style-redesign)이 같은 문제를 해결했으므로
그 디자인을 이 레포로 이식하되, **조리 중 화면은 이 레포의 원형(원 컨트롤)
배치를 유지**하기로 했다.

## 검토한 대안

- PR #63 코드를 통째로 복사 — 불가. 그쪽은 소셜 로그인/세션 토큰·태그 API 기반이라
  이 레포의 익명 베타 계정·API 계약과 어긋난다.
- 화면 코드에 색 리터럴 직접 기입(PR #63 방식) — 이 레포는 DesignSpec 토큰
  시스템이 있어 그 위에 얹는 쪽을 택했다. 팔레트가 `design_catalog.dart` 한 곳에
  남고, 디자인 스위처로 이전 안과 즉시 비교할 수 있다.

## 최종 결정

- `whiteCatalogSpec`(화이트 카탈로그)을 새 기본 디자인으로 추가. 흰 바탕 +
  버밀리언(#F04E23) 포인트, 차가운 중성색. 사진 플레이스홀더만 웜 톤 유지.
- 홈: 풀블리드 3:2 히어로(오늘의 추천 — 매번 랜덤, 요리 시작/저장 버튼) +
  가로 스크롤 포스터 열(내가 만든 요리 / 다시 만들까요 / 전체 레시피).
  이어하기·후기 초안 카드는 히어로 바로 아래로 이동.
- 검색: 세로 목록 → 사진 3열 그리드 + 재료 힌트 칩. 페이지네이션은 기존
  0-base 계약 그대로.
- 셸: 하단 탭 홈/검색/기록/내 정보 4개. 탭 상태를 `shell_tab.dart` 의
  ValueNotifier 로 빼서 어느 화면에서든 로고 탭 → 홈 복귀(`goHome`).
- 후기 화면 상단을 주황(accentHeader)으로 — 조리 종료 신호.
- cooklog 심볼·워드마크 이식(`lib/app/cooklog_mark.dart`, `assets/logo/`).
  로고 색은 테마와 무관하게 고정.
- **조리 중 화면(CookSessionScreen)은 미변경.**

## 검증

- 백엔드 전 엔드포인트를 배포 서버(168.107.11.255)에 대조 — 검색 라우트가
  서버에 없던 문제는 백엔드 레포 main 머지(229a04f)로 별도 해결.
- `dart analyze` 통과 확인 후 푸시가 원칙이나, WSL 환경에서 flutter 명령이
  불가해 analyze 는 Windows dart.exe 로 비동기 수행 중. `flutter test` 는
  Windows PowerShell 에서 실행 필요.

## 이후 작업에서 지킬 것

- 새 색·크기가 필요하면 화면 코드가 아니라 DesignSpec 토큰에 추가.
